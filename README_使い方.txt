電子黒板付き 写真台帳アプリ
Windows / iPhone / iPad対応

【基本的な使い方】
1. 「工事情報・保存」で工事基本情報を登録
2. 「台帳項目登録」で工事名・工種・工事内容・撮影箇所を登録
3. 「台帳一覧」で撮影する番号の「黒板に設定」を押す
4. 「黒板付き撮影」で現場写真を撮影または選択
5. 黒板の位置・大きさ・色を調整
6. 「黒板付き写真を台帳へ保存」を押す
7. 「完成台帳」で印刷またはPDF保存

【Windowsで使用】
1. ZIPファイルを展開
2. 「Windowsで起動.bat」をダブルクリック
3. EdgeまたはChromeが開きます
4. ブラウザのインストールボタンからWindowsアプリとして追加できます

【iPhone / iPadで使用】
同じWi-Fi上で一時的に使う場合：
1. Windowsで「Windowsで起動.bat」を実行
2. WindowsのIPアドレスを確認
3. Safariで http://WindowsのIPアドレス:8080 を開く
4. 現場写真はカメラから直接撮影できます

ホーム画面へ正式に追加する場合：
HTTPSで公開したURLをSafariで開き、
共有ボタン「□↑」→「ホーム画面に追加」を選択します。

【保存について】
・台帳情報はブラウザ内、写真はIndexedDBに保存します
・WindowsとiPhone/iPadのデータは自動同期されません
・別端末への移行には「バックアップ出力」と「復元」を使用してください
・ブラウザデータを削除するとアプリのデータも消える場合があります
