電子黒板付き写真台帳アプリ v4（アプリ内カメラ版）

主な追加機能
・アプリ画面内でカメラを起動
・撮影画面の右下に電子黒板をリアルタイム表示
・黒板を指でドラッグ移動
・2本指またはスライダーでサイズ変更
・四隅へのワンタップ移動
・黒板の一時非表示
・撮影前に黒板内容を編集
・黒板あり写真と元写真の両方を保存可能
・前面／背面カメラ切替
・カメラが使えない場合は写真選択で代用

GitHub Pages更新方法
1. このフォルダ内の index.html、sw.js、manifest.webmanifest、icons をリポジトリ直下へアップロードします。
2. 同名ファイルは上書きします。
3. Commit changesを押します。
4. 1〜3分待ち、iPhoneのホーム画面版を完全に終了して開き直します。
5. 古い画面のままならSafariで公開URLを再読み込みしてから、ホーム画面版を開き直します。

カメラについて
・GitHub PagesのHTTPS公開URLから開いてください。
・初回はカメラ許可が表示されます。
・iPhoneではSafariまたはホーム画面へ追加したアプリから利用できます。
